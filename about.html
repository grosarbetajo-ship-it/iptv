О проекте

Учебный статический IPTV-проект для публикации на GitHub Pages или Vercel.

Стек

HTML5, CSS3, JavaScript, Hls.js и localStorage. Backend не требуется.

Публикация

Содержимое репозитория можно публиковать через GitHub Pages из ветки main.

Развитие

Можно добавить EPG, авторизацию, API, базу данных, мониторинг потоков и серверный импорт.
